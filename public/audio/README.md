# 公共演讲音频

这些音频来自 Wikimedia Commons，属于美国政府作品（public domain），仅用于听力学习。

| 文件 | 内容 | 来源 |
|---|---|---|
| `jfk-inaugural.ogg` | John F. Kennedy, Inaugural Address (1961) | https://commons.wikimedia.org/wiki/File:JFK_inaugural_address.ogg |
| `fdr-fireside-1.ogg` | Franklin D. Roosevelt, First Fireside Chat (1933) | https://commons.wikimedia.org/wiki/File:Fireside_Chat_1_On_the_Banking_Crisis_(March_12,_1933)_Franklin_Delano_Roosevelt.ogg |

OGG 格式在 Chrome / Edge / Firefox 可直接播放；Safari 较新版本也支持。若无法播放，可点听力页的「音频来源 / 许可说明」在原站收听。
