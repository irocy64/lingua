# 外语学习网站开源项目调研报告

> **调研目标**：为自研"英语 + 日语双语学习网站"筛选可直接部署、可二次开发或可参考架构的开源项目
> **调研日期**：2026-10-20
> **使用者背景**：大学生，目标精通英语、日语；具备全栈开发能力（熟悉 Next.js / TypeScript 技术栈）
> **数据说明**：Star 数与活跃度通过 GitHub API / 项目官网获取，标注获取日期；个别项目因 API 限流未取得精确数值，以"—"标注，不做臆测

---

## 一、结论速览（TL;DR）

1. **没有任何一个开源项目同时完整覆盖"英语 + 日语 + 听说读写 + 背词"全部需求**，最佳策略是 **"组合部署 + 自研整合"**；
2. **日语学习**：首选 **Hanabira**（JLPT N5–N1 内容最全，可自托管，内容 CC 协议可复用），**KanaDojo**（代码质量最高、社区最活跃，适合做架构模板）；
3. **英日双语阅读**：首选 **Lute v3**（成熟稳定，支持 40+ 语言，日语 MeCab 分词，可导出 Anki）；
4. **AI 精读 / 口语**：参考 **OpenKoto**（AI 沉浸式阅读）与 **SpeakMate**（AI 英语口语对话）；
5. **自研核心组件**：复习调度直接采用 **FSRS**（`ts-fsrs` 库），例句数据采用 **Tatoeba**，避免重复造轮子；
6. **推荐技术栈**：Next.js 15 + TypeScript + Drizzle/Prisma + PostgreSQL，与 KanaDojo、LEAF 等主流项目一致。

## 四、重点项目详析

### 1. Hanabira —— 日语内容最完整的开源平台
- **功能**：JLPT N5–N1 语法、汉字、词汇、音频；YouTube 沉浸学习；个人词汇图谱（Knowledge Map，按汉字/复合词关联）；Mokuro 漫画 OCR 阅读器；
- **内容资产**：单独的日语/韩语内容仓库以 **CC 协议**发布（JSON 数据集，含词汇、语法、例句），**可在自研项目中合法复用（注明来源即可）**；
- **部署**：三条命令完成自托管（`git clone` → `docker-compose pull` → `docker-compose up`，默认端口 8888）；
- **定位**：Freemium + 开源，Public Alpha 阶段；
- **适用**：直接自用；复用其 JLPT 数据集；参考词汇图谱设计。

### 2. KanaDojo —— 社区最活跃、代码最现代的日语训练应用
- **功能**：平假名、片假名、汉字、词汇的四种 drill 模式；极简美学（灵感来自 Duolingo + Monkeytype）；
- **技术**：Next.js 15 + React 19，AGPL-3.0，Vercel 赞助，Docker 自托管；
- **社区**：3,692 stars，调研当日仍有提交，大量 good first issues；
- **局限**：是"训练工具"而非"系统课程"，文档对跨设备进度同步着墨较少；
- **适用**：**作为自研网站的前端架构模板与 UI 参考的首选**。

### 3. Lute v3 —— 通过阅读学语言的成熟方案
- **功能**：导入任意文本 → 点击生词即时查词典 → 按熟悉度给词着色 → 内置 SRS 复习 → 导出 Anki；支持多词短语、词条父子关系、图片联想；
- **语言**：支持 40+ 语言；**日语依赖 MeCab 分词**（官方推荐 Docker 镜像，依赖已内置）；
- **技术**：Python + Flask，MIT 许可证，pip 或 Docker 安装；
- **社区**：1,592 stars，活跃开发，有 Discord 社区；
- **适用**：英语/日语阅读输入的主力工具；参考其"文本 → 生词 → 复习"闭环。

### 4. LibreLingo —— 开源 Duolingo
- **功能**：技能树课程、听力听写、词组积木造句、迷你词典、间隔重复；离线优先（PouchDB）、跨设备同步；
- **课程体系**：课程以 **YAML 编写**，配套 Python 工具链与课程编辑器，可导出 JSON；可通过 GitHub gist 测试课程；
- **技术**：Svelte + TypeScript 纯静态前端（无后端）；
- **注意**：原项目一度停滞，现由社区维护；AGPLv3；
- **适用**：参考其课程数据结构与教学题型设计；自制日语课程的工具链。

### 5. OpenKoto —— AI 驱动的任意内容精读
- **功能**：一键导入 URL / Word / Markdown → 自动翻译 + 生词提取；沉浸式阅读器（实时语言切换、即点即查、语法解析）；AI 上下文讲词、语法拆解、发音指导；YouTube 视频学习；
- **技术**：桌面端 + Web，Apache-2.0（最宽松的许可证之一）；
- **适用**：AI 精读模块的直接参考，适合处理你感兴趣的真实材料（新闻、论文、生肉）。

### 6. SpeakMate —— 本地 AI 英语口语伙伴
- **功能**：与 AI 自然对话，对话中温和纠正语法与措辞；无压力、去干扰界面；
- **技术**：MIT，Hacktoberfest 2026 项目；
- **适用**：英语口语模块参考，可扩展为日语语音对话（结合语音识别 + TTS）。

### 7. LEAF —— Duolingo 式游戏化骨架
- **功能**：生命值、排行榜等游戏化机制；
- **技术**：Next.js + TypeScript + Drizzle ORM + Neon DB，MIT；
- **适用**：游戏化系统与现代全栈工程结构参考。

## 六、自研路线建议（分阶段）

### 阶段 0：先用起来（1 周）
- 自托管 **Hanabira**（日语）+ **Lute v3**（日语+英语阅读）+ 试用 **SpeakMate**（英语口语）；
- 目标：在真实学习中记录痛点，形成需求清单。

### 阶段 1：MVP 骨架（3–4 周）
- 以 **KanaDojo** 为前端模板，Next.js 15 + TypeScript + PostgreSQL + Drizzle；
- 核心模块：用户系统 → 词库（导入 Hanabira JSON + Tatoeba 句库）→ **FSRS 复习闭环**；
- 语言模块先做日语假名/汉字/词汇 drill，英语做 CET-6/考研词汇。

### 阶段 2：输入能力（4–6 周）
- 阅读器：参考 Lute/OpenKoto，实现文本导入、即点即查、生词自动入复习队列；
- 日语接入 MeCab 分词；英语/日语均接入词典与发音 TTS。

### 阶段 3：AI 与输出（6 周+）
- AI 精读讲解（参考 OpenKoto）；
- AI 对话（参考 SpeakMate）：英语口语为主，复用个人音色 TTS（与既有 AI 语音工作流一致）；
- 写作批改：接入大模型逐句批改。

### 阶段 4：游戏化与多端
- 生命值/连击/词汇图谱（参考 LEAF、Hanabira Knowledge Map）；
- PWA 多端适配与进度同步。

### 许可证注意事项
- **MIT / Apache-2.0**：可自由闭源商用（Hanabira、Lute、OpenKoto、SpeakMate、LEAF）；
- **AGPL-3.0**：KanaDojo、LibreLingo——若直接复制其代码并提供网络服务，**衍生作品须同样开源**；仅参考架构思路、独立实现不受限，但建议咨询具体条款；
- **CC 协议内容**：按要求署名（Hanabira 内容注明 hanabira.org，Tatoeba 句对遵守其 CC 许可）。
